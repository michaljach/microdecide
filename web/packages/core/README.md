# @nodd/core

Shared by [`@nodd/browser`](https://www.npmjs.com/package/@nodd/browser) and
[`@nodd/node`](https://www.npmjs.com/package/@nodd/node): the `nodd.json` model config validator
(generated from the Python exporter's schema), the `Decision` type, and logits → `Decision`
(temperature-scaled softmax, Unicode-safe input clipping). You normally install one of those
two, not this.
